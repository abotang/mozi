# 墨子 API 与任务脚本交付包

## 目录

- `墨子API/`
  - `api_docs/`：用户提供 Apifox 项目的 154 个原始接口文档。
  - `Apifox全量索引.txt`：接口分类和原始链接。
  - `墨子API聚合参考.md`：本地资料与前端调用证据的扩展聚合参考。
- `墨子任务脚本/`
  - 七个按任务拆分的 PowerShell 入口脚本。
  - `08-删除任务及对应区域.ps1`：删除任务，并按需连带删除该任务的专属区域。
  - `Invoke-MoziBlueMissionPlan.ps1`：共享执行引擎。
  - `墨子蓝方七类任务配置.json`：修改单元、目标、区域、挂载等参数。
- `说明文档/`
  - `墨子蓝方七类任务复用说明.md`：脚本使用方法。
  - `墨子API与蓝方海空任务实测手册.md`：全量 API 索引、50 个任务模板映射和实测流程。

## 建议使用顺序

1. 阅读 `说明文档/墨子蓝方七类任务复用说明.md`。
2. 修改 `墨子任务脚本/墨子蓝方七类任务配置.json`。
3. 先对目标任务脚本运行 `-ValidateOnly`。
4. 再执行对应任务脚本。
5. 查看配置中的 `reportPath` 输出，确认区域、目标和分配单元均已回读。

删除任务时使用 `08-删除任务及对应区域.ps1`。巡逻/预警任务传入 `AreaGuid` 会在任务删除并回读确认后继续删除区域；没有区域的打击任务不传 `AreaGuid`。

## 重要提醒

- 想定重启后，任务、区域和 contact GUID 需要重新获取。
- 打击任务的目标必须是蓝方当前 contacts 中的 GUID。
- 当前示例没有合法地面接触，因此飞机对地打击默认关闭。
